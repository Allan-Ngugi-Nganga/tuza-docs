# Tuza docs

The manual for [Tuza](https://tuza.stream), the tipping tool that puts a viewer's
M-Pesa tip on a Kenyan streamer's screen in seconds.

**Read it at [docs.tuza.stream](https://docs.tuza.stream).**

## What is in here

| Page | What it answers |
| --- | --- |
| [Start here](https://docs.tuza.stream/) | what Tuza is, and which page you need |
| [Your overlay](https://docs.tuza.stream/overlay/) | getting alerts on screen in OBS |
| [Sounds and alerts](https://docs.tuza.stream/sounds/) | what a tip sounds like, and which gifts are worth an alert |
| [Money](https://docs.tuza.stream/money/) | what a viewer pays, what you keep, when it arrives |
| [Song requests](https://docs.tuza.stream/songs/) | Spotify, and `!play` in chat |
| [API reference](https://docs.tuza.stream/api/) | overlay events, for anyone building against them |

## Who it is for

Streamers first. The instructions assume you can open OBS and click a button, and
that you have never read an API document in your life.

The API section exists because the overlay is a web page, and some people want to
build their own. It is the last section, not the first.

## If something is wrong or missing

Open an issue on this repository, or write to
[allan@ngugi.work](mailto:allan@ngugi.work). Say which browser you are on and
which version of OBS you are running, because those two answer most questions.
