# Sounds and alerts

A tip is a moment. A sound is what makes people look up.

## The three you get

Every account has a default alert. You can add **small** and **big** tiers on top of it,
and set the coin value where each one starts. A KES 20 tip plays the default; a KES 500
tip can play the big one, with a longer card on screen.

Set the thresholds in the dashboard under alerts. They are per account, so a creator who
gets many small tips and one who gets a few large ones can both be happy.

## Upload your own

Upload an MP3, WAV, M4A or OGG and Tuza converts it once, so it plays the same on every
machine:

- audio only, mono, so a stereo file cannot clip
- normalised to -16 LUFS, which is the level OBS expects
- keyed by a hash of the result, so uploading the same file twice costs one object

The conversion is why an upload takes a few seconds. It is also why a 40 MB WAV from a
friend plays instantly afterwards.

## Gifts and gifts-only alerts

Gifts from TikTok are not money. They appear as an alert and in your gift history with
coins, and they never appear in earnings, because no money reached you. A dashboard that
added the two together would be lying with a chart.

You can require a gift to trigger an alert, and set which gift level is enough. That
keeps a Rose from firing the same animation as a Universe.
